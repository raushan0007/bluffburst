# BluffBurst! — Catch the Lie

A real-time multiplayer bluffing party game for 2–8 players. No logins, no installs: one person creates a room, everyone else joins from their own phone or laptop with a 4-letter room code.

## How to play
1. **Read the fact.** One word or phrase is missing.
2. **Write a lie.** Type a fake answer that sounds true. Typing the real answer is not allowed.
3. **Spot the truth.** All lies and the real answer are shuffled. Pick the one you think is real. You can't pick your own lie.
4. **Score.** +1,000 for finding the truth. +500 for every player who falls for your lie.
5. **Win.** The last round is worth double. Highest score after the final round wins.

## Run locally
```
npm start
```
Then open http://localhost:3000. No dependencies needed (Node 18+).
